# PNG to GIF Converter - React Version

## 🚀 Новая React версия с улучшенным интерфейсом!

Приложение теперь поддерживает две версии фронтенда:
- **Обычная версия** - на чистом HTML/CSS/JS 
- **React версия** - современный интерфейс с React + styled-components

## 📦 Установка и запуск

### Обычная версия (как раньше)
```bash
npm start
# или
npm run dev
```

### React версия (новая!)
```bash
npm run dev:react
```

## 🎨 Что нового в React версии

### Компонентная архитектура
- **Атомарные компоненты**: Button, Input, Card, Section
- **Styled Components** для стилизации
- **Модульная структура** для легкого расширения

### Улучшенный UX/UI
- 🎯 **Адаптивные состояния** кнопок (hover, focus, disabled)
- ⚠️ **Цветовая индикация** результатов (желтые карточки для предупреждений)
- 📊 **Прогресс-бар** с детальной информацией
- 🔄 **Автоматические обновления** статуса

### Исправлена проблема со сжатием
- ✅ **Сохранение лучшего результата** даже если не удалось уложиться в лимит
- ⚠️ **Предупреждающие карточки** для файлов, превышающих 510KB
- 📈 **Улучшенная логика сжатия** с адаптивными алгоритмами

## 🏗️ Структура React версии

```
src/react/
├── index.jsx                 # Точка входа
├── App.jsx                   # Главный компонент
└── components/
    ├── Button.jsx            # Кнопки с состояниями
    ├── Input.jsx             # Поля ввода
    ├── Card.jsx              # Карточки результатов
    ├── Section.jsx           # Секции страницы

## 🛠️ Сборка для продакшена

```

## 🔧 Технические детали

### Интеграция с Electron
- **Полная совместимость** с существующим electronAPI
- **Автоматическая сборка** React при первом запуске
- **Безопасная загрузка файлов** через file:// протокол

### Компоненты
- **Button**: поддерживает primary, secondary, ghost стили
- **Input**: с суффиксами и валидацией  
- **Card**: с состояниями success, warning, error
- **ProgressBar**: с анимацией и деталями процесса

### Styled Components
- 🎨 **Градиенты** и современные эффекты
- 📱 **Адаптивность** для разных размеров окна
- 🌓 **Готовность к темной теме** (базовая поддержка)

## 📋 Основные улучшения

1. **Исправлена критическая ошибка**: теперь сохраняется лучший результат сжатия
2. **Предупреждающие карточки**: четкая индикация проблем с размером
3. **Улучшенная архитектура**: модульные компоненты для легкого расширения
4. **Современный интерфейс**: соответствует актуальным дизайн-трендам

## 🎯 Использование

1. **Выберите папку** с PNG изображениями
2. **Настройте параметры** (длина кадра, размер)
3. **Нажмите "Жмахнуть ЖИФ"** 
4. **Просмотрите результаты** с цветовой индикацией

Файлы, превышающие лимит 510KB, будут помечены желтыми карточками с предупреждением, но все равно сохранены в лучшем возможном качестве!
