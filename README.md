# ЖИФ

Конвертер PNG в GIF.

Простое кроссплатформенное приложение для конвертации PNG-файлов в GIF-файлы с контролем размера.

## Функции

- Выбор директории с PNG-файлами
- Настройка максимального размера GIF-файлов в килобайтах
- Конвертация всех PNG-файлов в выбранной директории в GIF-формат
- Работает на macOS и Windows без необходимости установки

## Запуск приложения

### macOS
1. Откройте терминал
2. Перейдите в директорию с приложением: `cd /path/to/png-to-gif-converter`
3. Сделайте скрипт запуска исполняемым: `chmod +x run.sh`
4. Запустите скрипт: `./run.sh`

### Windows
1. Откройте проводник Windows
2. Перейдите в директорию с приложением
3. Запустите файл `run.bat` двойным кликом

## Сборка портативных версий

### macOS
1. Откройте терминал
2. Перейдите в директорию с приложением: `cd /path/to/png-to-gif-converter`
3. Сделайте скрипт сборки исполняемым: `chmod +x build-mac.sh`
4. Запустите скрипт: `./build-mac.sh`
5. После завершения сборки, DMG-файл будет находиться в папке `dist`

### Windows
1. Откройте проводник Windows
2. Перейдите в директорию с приложением
3. Запустите файл `build-win.bat` двойным кликом
4. После завершения сборки, EXE-файл будет находиться в папке `dist`

## Требования для разработки

- Node.js (рекомендуется версия 16.x или выше)
- npm (обычно устанавливается вместе с Node.js)

## Использованные технологии

- Electron.js
- React
- Jimp (для обработки изображений)
- GIFEncoder (для создания GIF-файлов)
